/portfolioСтатическая страница. Collection List «Кейсы», сортировка по Editorial priority. Внутри элемента — компонент Case Card. Сетка Grid: 2 колонки на десктопе, 1 на планшете и телефоне.
/portfolio/[slug]Collection Template «Кейсы». Hero из Cover, блоки фактов, задачи, решения и объёма. Галерея — Collection List из Multi-image Gallery + Webflow Lightbox. Похожие — Collection List «Кейсы» с фильтром по совпадающему формату, исключая текущую запись.
КомпонентыHeader и Footer действующего сайта, Case Card (props не нужны — поля привязаны в CMS-контексте), Filter Bar, CTA «Обсудить проект», Section Title.

3. Штатно и надстройки

Штатно в Webflow Коллекции, Multi-reference, Multi-image, Collection List и Template, условная видимость пустых полей, Lightbox для галереи, Grid/Flex и брейкпоинты, компоненты, SEO-поля шаблона.
Finsweet Attributes v2 — List Поиск, мультифильтры, счётчик результатов, сброс и пустое состояние. На Collection List: fs-list-element="list" и fs-list-load="all", чтобы фильтр учитывал весь каталог, а не первую порцию. Форма фильтров — fs-list-element="filters"; чекбоксы — fs-list-field="format" / "industry" и fs-list-value; поиск — fs-list-field="*". Счётчик — results-count, сброс — clear, «Ничего не найдено» — empty. Значения Multi-reference выводятся вложенным списком внутри карточки с тем же fs-list-field. Внутри группы — «или», между группами — «и».
Свой скрипт ~30 строк Подмена hero по наведению, фокусу и касанию миниатюры; возврат обложки при уходе курсора; сохранение фильтров в URL и позиции прокрутки в sessionStorage при переходе в кейс. Подключается в Page Settings → Before body. 
document.querySelectorAll('[data-case-card]').forEach(card => {
  const hero = card.querySelector('[data-case-hero]');
  const cover = hero.src, coverSet = hero.srcset;
  const show = t => { hero.src = t.dataset.full; hero.srcset = ''; mark(t); };
  const mark = t => card.querySelectorAll('[data-case-thumb]')
    .forEach(b => b.setAttribute('aria-pressed', b === t));
  card.querySelectorAll('[data-case-thumb]').forEach(t => {
    const img = new Image(); img.src = t.dataset.full;   // предзагрузка
    t.addEventListener('mouseenter', () => show(t));
    t.addEventListener('focus', () => show(t));
    t.addEventListener('click', e => { e.preventDefault(); show(t); });
  });
  card.addEventListener('mouseleave', () => { hero.src = cover; hero.srcset = coverSet; mark(null); });
});

4. Порядок переноса

1. Создать справочники «Форматы» и «Отрасли», затем коллекцию «Кейсы» с полями выше.
2. Импортировать 32 записи через CSV (тексты, теги, приоритет), изображения загрузить в Cover, Thumb 1–4 и Gallery.
3. Собрать Case Card и страницу /portfolio, привязать поля, настроить условную видимость.
4. Собрать Collection Template кейса, галерею с Lightbox и блок похожих проектов.
5. Подключить Finsweet Attributes (List) и скрипт карточек, проверить фильтры на всём каталоге, мобильную версию и клавиатуру.
6. Перед публикацией заменить иллюстрации в кейсах с пометкой на отчётные фотографии, если они появятся.
